# Investment & Asset Management Showcase Instructions

เว็บนี้เป็น public-safe static showcase ของ vertical Investment & Asset Management เท่านั้น เก็บเฉพาะ positioning, scope และ readiness ที่อนุมัติให้เปิดเผย

ห้ามเพิ่ม client records, candidate data, threat data, transaction records, health data, credentials, private dashboard links, API routes, lead collection หรือคำกล่าวอ้างเรื่องลูกค้า/ผลลัพธ์ที่ยังไม่มีหลักฐาน

ก่อนแก้ Next.js ให้อ่านเอกสารใน `node_modules/next/dist/docs/` ที่เกี่ยวข้อง และรักษา static export ที่ `npm run check` ตรวจได้
